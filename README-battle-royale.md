## 这个包是什么

自带全部素材（美术、3D 棋盘贴图、中/日语音、字体、教程图）与 `node_modules` 的**完整包**，
解压、双击启动脚本就能开服，不需要联网下载素材。部署端口 **4040**，与 3000 端口的另一份安装完全隔离，
可以同时运行。需要 Node.js 22 或更高版本。

## 相对上游 v0.2.6 的改动

详见 `MODIFICATIONS.md`（GPL-3.0 第 5 条要求的改动声明）。要点：

- 目标生命值（血量）上限 **30**；一回合扣血上限默认 10，可用开关关掉（关掉即扣血无限制）；
- 公共卡池的角色 **无限张**（保留上游按剩余份数加权的抽卡概率，只把每名干员的上限放大）；
- **装备无限量供应**（取消共享库存上限）；
- **没有联防**：漏怪直接扣血；
- **出怪掷骰子**：每一波的敌人从全部怪物里随机抽；**第 1–13 回合按官方规则出怪，第 14 回合起掷骰子（所有怪物）；
- 怪物数值：第 1–13 回合官方表，**第 14 回合起血量每回合翻倍**；
- **第 20 回合强制首领战**：领袖血量固定 **十亿**、**限时 2 分钟**，战斗结束即结束这一把；
- **扣血加钱按钮**（休整期顶栏）：3 滴血换 1 资金；低于 3 滴不能用；刚好 3 滴可以使用，但用完当场淘汰；
- 「禁用阵营」机制保留上游原值（哪些盟约被禁、哪些干员不出现，开局与对局中都能查看）；
- 启动脚本会**自动检测 4040 端口**：被占用就自动关掉占用它的进程；同时监听 3000 的进程一律不动。

## 怎么开服

1. 解压本包，得到里面的 `Stronghold-Protocol` 文件夹（放在哪里都行）；
2. 双击 `启动服务器-4040.bat`，按菜单提示选 `1` —— 选 `2` 可以切换"回合扣血上限"的开关，选 `3` 看当前规则；
3. 浏览器打开 `http://localhost:4040`；局域网玩家用 `http://开服电脑的IP:4040`（启动时窗口里会打印地址）；
4. 停止服务器：在启动窗口按 `Ctrl+C`，或直接关掉窗口。

也可以不用脚本：`set PORT=4040 && npm start`（或 `node server/index.js`）；健康检查 `GET /healthz`。

## 以后怎么升级

本包内含 `MANIFEST.json`（本版本全部程序文件的清单）。以后若拿到只含改动文件的**更新包**
（`Stronghold-Protocol-v<版本>-update.zip`），按 `冷更新说明.md` 的步骤操作即可：
**先停服**（更新包不会自己停服，`先停服再解压.bat` 可以帮忙）、把更新包内容解压覆盖到本目录、再启动。
